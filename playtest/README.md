# Windows playtest zip

Paczka `PelotonManager-playtest-windows.zip` jest publikowana w **GitHub Releases** tego repozytorium
(zakładka *Releases* po prawej stronie strony głównej repo). Pobierz najnowszy wpis `playtest-YYYY-MM-DD`.

Nowa gra: wybór klubu WorldTour, plan sezonu, potem biurko. Finanse i oferty na składzie są ze świata (euro).

Rozpakuj cały folder i kliknij `PelotonManager.exe`. Instrukcja: `CZYTAJ_MNIE.txt`.

Dla agentów: paczkę buduje workflow `.github/workflows/playtest-windows.yml`
(`tools/pack-windows-playtest.sh`) po wypchnięciu tagu `playtest-*`. Nie commitujemy zipa do repo (D-053).
