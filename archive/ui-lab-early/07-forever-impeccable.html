Nowe źródła: Forever i Impeccable

To nie jest kolejny dashboard. To dwa narzędzia dla Codexu: skąd brać gotowe kawałki UI i czego nigdy nie rysować.

SOURCE 01

Forever Infinite

forever-components.vercel.app/infinite

Płótno 600+ pojedynczych komponentów HTML (CSS / Canvas / SVG, zero zależności). Agent ma szukać i składać, nie wymyślać „ładnego AI UI” od zera.

  • indeks: https://raw.githubusercontent.com/isas1/forever-ai-components/main/infinite/components.index.json
  • wejście agenta: https://raw.githubusercontent.com/isas1/forever-ai-components/main/agents.json
  • filtruj w kodzie; nie wklejaj całego indeksu do kontekstu
  • preferuj perfTier: cheap, mobile-ready, accessible; unikaj expensive motion
SOURCE 02

Impeccable slop

impeccable.style/slop

Lista rozpoznań „AI look”. Każdy nowy prototyp ma przejść tę checklistę. Jeśli reguła strzela — poprawiasz, nie bronisz.

  • fioletowe gradienty, glassmorphism, neon glow, blur orbs
  • side-tab card (gruba kolorowa krawędź z boku zaokrąglonej karty)
  • karty w kartach, hero-metric, identyczne siatki ikona+nagłówek
  • Inter / Geist / Space Grotesk / Instrument Serif na wszystko
  • gradient text, pulsing dots, bounce easing, eyebrow/kicker nad H1

Jak tego używamy. Forever = skąd brać. Impeccable = czego nie wypuszczać. DNA gry zostaje z tablicy 02 (Football Manager / Motorsport Manager / PCM) i z locków: Advance Day, na dniu wyścigu guzik Race next wchodzi w przygotowanie. Skrzynka jest kolejką spraw, nie drzwiami do wyścigu. Żadnego KPI dashboardu jak w odrzuconym Career Hub.
