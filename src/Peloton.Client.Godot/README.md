# Godot client stub

This project is the Godot presentation client. Headless tests and `Peloton.SimRunner` remain the executable surfaces without the Godot editor.

The thin Career Hub (`CareerHub.tscn`) is the main scene: Advance Day, Race next, calendar, inbox, prep seats, and **results by default**. Watch film is a Hub setting (`FILM: WYŁ/WŁ`), off by default. `WatchRace.tscn` still opens the stage window on its own. UI issues Application Commands and knowledge-bounded Queries; it does not own World State or open SQLite.

Player-facing description: `HOW_RACE_DAY_WORKS.md`.
